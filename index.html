Made from 4 forgotten tools

Turn old scanned papers
into useful data.
Really simply.

A friendly tool that helps students, teachers, and regular people pull numbers and information out of old PDFs and images.

Get started in 5 minutes

The 4 old tools I combined

Plot Digitizer
suhasjains/MyPlotDigitizer (2017)

Turns graphs from old papers into numbers you can use in Excel.

Document Layout Finder
rbaguila/document-layout-analysis (2020)

Finds text, paragraphs and important sections on scanned pages.

Audio Spectrogram Tools
xmikos/simplespectral (2017)

Helps work with sound wave data and graphs.

Simple FITS Reader
Old astronomy community code

Basic support for special astronomy image files.

How to try it

  1. 1. Install Python from python.org
  2. 2. Download this repository
  3. 3. Open terminal and run: pip install streamlit
  4. 4. Run: streamlit run app.py
